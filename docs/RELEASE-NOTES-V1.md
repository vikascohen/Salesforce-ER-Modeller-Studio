# ER Modeller Studio — Version 1 Stable

**Branch:** `version-1-stable`  
**Status:** Stable  
**Author:** Vikas Cohen

Version 1 is the original stable release of Salesforce ER Modeller Studio. It establishes the core visual ER modelling experience, DSL-driven modelling workflow, schema visualisation, diagram editing, import/export capabilities, Data Dictionary features, themes, and the supporting Salesforce components used by the Studio.

## Installation

Version 1 is available as an unmanaged Salesforce package.

- Production package ID: `04taj000000gRTd`
- Sandbox package ID: `04taj000000gRTd`
- Source branch: `version-1-stable`

The Production and Sandbox installation links are provided in the repository README.

## Release preservation

The `version-1-stable` branch preserves Version 1 independently of Version 2. Version 2 development and releases do not modify this stable Version 1 branch.

For the newer architecture-intelligence release, see `docs/RELEASE-NOTES-V2.md`.
